First public preview of MT6893 Spatial Audio AOSP for the inspected Realme X7 Max
RMX3031 Evolution X Android 17 12.3 audio build.

- Original Oplus headphone tuning and channel compatibility adapter.
- Native Original / Spatial Audio controls, headphone status and saved selection.
- Glow-ring WebUI with xCaptaiN09 credit, channel demo and explicit diagnostics.
- Guarded installation and source/build provenance.

**Known issues:** YouTube test-video LFE rumble remains absent during live
playback, and Surround Sound Test can crackle after short channel clips. Neither
issue is declared fixed. Other ROM builds, devices, Bluetooth and head tracking
are not validated.

Install the `MT6893-Spatial-Audio-AOSP-v0.1.3-preview.zip` asset through your root
manager with a working mounting provider, then reboot. The tested provider is
Magic Mount-rs v4.1.12-959. Existing previews retain the same module ID and saved
selection. GitHub's automatic source archives are not flashable modules.

Verify the ZIP using the accompanying `.sha256` file. If audio or routing fails,
select Original or disable the module and reboot. See README for scope and details.

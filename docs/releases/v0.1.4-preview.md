Preview release of MT6893 Spatial Audio AOSP expanding installer compatibility to Android 16 (SDK 36) and Android 17 (SDK 37) AOSP ROMs on Realme X7 Max (RMX3031).

- Added Android 16 (SDK 36) support alongside Android 17 (SDK 37).
- Expanded MT6893 / RMX3031 board detection across fallback properties and vendor HAL presence (validated on LineageOS Android 16 and Evolution X Android 17).
- Logged base vendor file differences as warnings instead of aborting installation across different ROM builds.
- Retained the original Oplus v0.6 headphone tuning, channel compatibility adapter, and glow-ring WebUI with xCaptaiN09 credit.

**Known issues:** YouTube test-video LFE rumble remains absent during live playback, and Surround Sound Test can crackle after short channel clips.

Install the `MT6893-Spatial-Audio-AOSP-v0.1.4-preview.zip` asset through your root manager with a working mounting provider, then reboot. Verify the ZIP using the accompanying `.sha256` file.
